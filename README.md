# 东北三省美术纯艺考研速查（2028）

**在线地址：** https://ts-jj.github.io/northeast-art-kaoyan/

面向 2028 考研（2027 年 12 月初试）的美术纯艺方向择校速查，已排除哈尔滨。

## 内容

- 艺术学国家线参考（A 区 2024–2026）
- 专硕 / 学硕 / 学科教学（美术）三类专业横向对比
- 院校难度分档（A / B / C），含招生人数、初试科目、学费
- 黑龙江非哈尔滨院校特别说明（牡丹江师范学院无美术硕士点）
- 选校必须避开的 4 个坑
- 备考时间线（2026.10 – 2028.09）
- 各校研究生院官网直达

## 说明

单文件静态页面，无任何外部依赖，直接打开 `index.html` 即可，手机端会自动切换为卡片式布局。
